# Shared Command Definitions

## 1. Resolve every invocation

1. The active Role Lifecycle selects when to invoke a Command.
2. Resolve the invoking Identity, Responsibility and Scope from current System Context.
3. Resolve read sources and authorized write destinations through Identity Context and applicable System Rules.
4. Apply current approved customization and the relevant packaged template.
5. Report missing definitions or dependencies. Do not claim incomplete actions succeeded.
6. Commands do not create authority or duplicate the Lifecycle's stage order.

## 2. Record and resource Commands

1. **CREATE RECORD.** Create the selected record category at its authorized destination.
   Select the applicable record template:

   - Meeting Working Record: [Working Records template](../../../templates/working-records.md).
   - Final Minutes: [Minutes template](../../../templates/minutes.md).
   - Job Record: [Job Records template](../../../templates/job-records.md).

   Use the actual metadata for that record category.
   For a Meeting Working Record or Job Record in Google Docs, create a new native Tab in its existing file.
   Verify the saved content and required Formatting.
2. **SAVE OUTCOMES.** Save accepted outcomes at the current Lifecycle's required checkpoint.
   Preserve exact source relationships and material meaning. Verify the actual saved resource.
3. **VERIFY DELIVERABLE.** Inspect the complete latest saved artifact using [Quality criteria](../../workflow-qa/references/quality.md).
   Record Content, Writing and Formatting results and permitted corrections.
4. **UPDATE CONTEXT.** Consolidate current Identity operating information into the owning Identity Context.
   Preserve the six required Chapters, source authority and valid future work.
5. **UPDATE INDEX.** Maintain the applicable closed-record or Deliverable package row with exact authoritative locators and verified keys.
   Use the relevant [index template](../../../templates/index.md). Verify the saved row.

## 3. Messaging and knowledge Commands

1. **READ MESSAGES.** Use the [Inbox skill](../../inbox/SKILL.md) to read referenced records and route their outcomes.
2. **SEND WORK REQUEST.** Send an authorized bounded request through the exact registered recipient's inbox.
   Preserve its source and originating closed record.
3. **SEND COMPLETION NOTICE.** Send verified outcomes and references after the full assigned Protocol.
   Determine recipient relevance from originating Scope and current responsibilities.
4. **SEARCH EXPERIENCES.** Discover relevant Knowledge Bases and assess applicable advisory learning using [Knowledge Base](../../knowledge-base/SKILL.md).
5. **CONSOLIDATE KNOWLEDGE.** Integrate verified scoped subject information into the complete current authoritative Knowledge Base.
6. **CAPTURE EXPERIENCE.** Review the full lifecycle's actual evidence and consolidate useful learning, or return an explicit no-action conclusion.

Use host tools and practical methods that fit the action and granted permissions.
Keep further Command customization discoverable through the invoking Identity's operating references.
