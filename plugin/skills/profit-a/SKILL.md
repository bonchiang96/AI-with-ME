# PROFIT + A

1. Apply the complete [PROFIT + A Framework](references/framework.md).
2. Define Persona, Result, Objective, Feed, Insight and Template for the actual Task.
3. Use complete PROFIT + A for every Sub-agent Prompt and Plugin Development Prompt.
4. Select Provide Now, Provide Later or Continuous Feed according to the actual source arrangement.
5. Keep Acknowledgement last and use its defined readiness handshake.
6. Keep Feed In separate as the preparation list for the user.
7. Arrange the elements naturally while preserving every required meaning.
8. In the final Prompt, I means the user and You means the AI.
9. During Framework review, describe definitions naturally without forcing final Prompt pronouns.
10. Apply packaged [Writing Rules](../../rules/global-writing-rules.md) Strict Mode to the final Prompt.

The linked Framework owns the complete element definitions and the handshake for each Feed Mode.
