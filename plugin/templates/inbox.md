# 02 Inbox

## 1. Operating Guide

1. **Purpose.** The inbox receives Work Requests and Completion Notices for this Identity.
   Other Identities write rows here. This Identity reads and processes them.

2. **Names.** The file name is 02 Inbox.
   It resides in the Identity's identity folder.

3. **Metadata.** The file needs no metadata beyond its title.

4. **Sections.** The file has these Chapters:

   1. Operating Guide.
   2. Messages.

5. **Formatting.** Use a Google Docs file with one native table.
   Each row has five columns:

   1. Sent. Its format is pending design.
   2. From: the sender Identity's exact Agent Key.
   3. Type: Work Request or Completion Notice.
   4. Ref: the key of the closed record in the sender's index.
   5. Message: the message text.

   Write messages in Strict Mode under the Global Writing Rules.

6. **Local QA criteria.** Check these points:

   1. The sender verifies its saved row.
   2. The receiver deletes each row after processing it.
