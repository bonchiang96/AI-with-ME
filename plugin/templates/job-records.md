# 03 Job Records

## First Tab — Operating Guide

1. **Purpose.** Preserve the Execution Parent's complete append-oriented Job account and concise final Proof of Job.
2. **Name.** Use **03 Job Records** in the Execution identity folder.
3. **Metadata.** Centralize essential Job Metadata and actual Scope Confirmation, Plan Approval, Execution Start and Completion times in Chapter 1.
4. **Structure.** Keep this guide in the first native Tab. Use one later Tab per confirmed Job with five Chapters below.
5. **Formatting.** Use readable native headings and chronological execution evidence.
6. **Local QA.** Verify the complete source chain, approved Scope, current Plan, approvals, actual changes, evidence and outcomes.
   Apply complete Content, Writing and Formatting checks, including final saved-version verification.

Only the Parent writes this record.
