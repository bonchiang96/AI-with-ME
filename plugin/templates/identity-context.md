# 00 Identity Context

## 1. Operating Guide

1. **Purpose.** Identity Context is the Identity's consolidated starting context for work.
   It holds current working information, future work and operating references.
   Complete historical evidence belongs in the original Records and Minutes.

2. **Names.** The file name is 00 Identity Context.
   It resides in the Identity's identity folder.

3. **Metadata.** Record these items under this Operating Guide:

   - Agent Key.
   - Role.
   - Identity folder Locator.

   Responsibility and Scope are authoritative in System Context.

4. **Sections.** The file has these six Chapters in this order:

   1. Operating Guide.
   2. Future Topics.
   3. Working Group.
   4. Important Learning.
   5. Important Things or High-Priority Items.
   6. Knowledge Bases.

   The Identity controls content organization within each Chapter.
   Keep each Chapter's meaning within its purpose.

5. **Formatting.** Use a Google Docs file.
   Use Standard Mode under the Global Writing Rules.
   Use one readable list for Future Topics.
   Use a native table for Knowledge Bases.

6. **Local QA criteria.** Check these points after each change:

   1. The file holds only current truth, maintained by consolidation.
   2. The Context management rules in item 7 are met.
   3. Every Future Topic entry has its required fields.
   4. Every Knowledge Bases entry has Name, Location and Relation.

7. **Context management.** Apply these rules:

   1. Update independently derived information whenever useful within Responsibility and Scope.
   2. Enter user-confirmed Meeting matters only after verified Closed Minutes.
   3. Preserve the relevant source reference.
   4. Distinguish sources for reading from authorized record-writing destinations.
   5. The Agent judges when an update is needed.

8. **Operating references.** List here:

   - Target Locations for additional Identity-owned records or resources.
   - Discoverable Command definitions.
   - Workflow references, useful Workflow usage and the current Workflow stage.
   - Related Minutes and meaningful verified accomplishments.

## 2. Future Topics

A Meeting Agent entry has:

- Topic Name.
- Short Description.
- Precise source reference.

An Execution Agent entry for pending work has:

- Work Request Ref and From values.
- Specific Agent-authored Description.
- Exact sources.
- Relevant prerequisites.

Keep one readable list. Exclude statuses, counters and removal history.
