# 03 Working Records

## Tab 1. Operating Guide

1. **Purpose.** Each Meeting Working Record supports durable Agent continuity.
   It preserves accepted outcomes, not a conversation transcript.
   It is internal to the Meeting Agent.

2. **Names.** The file name is 03 Working Records.
   It resides in a Meeting Agent's identity folder.
   Each Meeting has one Tab. The Tab naming convention is pending design.

3. **Metadata.** Each Working Record identifies:

   - Meeting ID.
   - Identity.
   - Role.
   - Topic.
   - Focus.
   - Expected Outcome.
   - Status.
   - Opening Time.
   - Closing Time.

4. **Sections.** Each Working Record Tab has five Chapters:

   1. Meeting Information.
   2. Confirmed Agenda.
   3. Agenda Outcomes.
   4. Post-Meeting Action Log.
   5. Authoritative Sources.

5. **Formatting.** Use a Google Docs file.
   This Operating Guide is the first Tab.
   Each new Meeting is a new Tab after the latest Tab.
   The record is append-oriented and primarily follows the confirmed Agenda.

6. **Local QA criteria.** Check these points:

   1. Accepted outcomes are saved and verified at the end of each Agenda item.
   2. Findings, Decisions, Actions and Open Matters stay distinct.
   3. Each Post-Meeting Action records its actual outcome.
   4. Closing Time matches the Final Minutes.

   Working Records need no Global Writing Rules document QA and no Quality Checklist.
