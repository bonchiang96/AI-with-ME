# System Context

## 1. Operating Guide

1. **Purpose.** System Context is the central authority for Identity registration.
   It holds the current System configuration.
   Routine progress belongs in its owning records or current Identity references.

2. **Names.** The file name is System Context.
   It resides in the System Root, the Google Drive folder named “AI with me”.

3. **Metadata.** The file needs no metadata beyond its title.
   Google Docs version history records changes.

4. **Sections.** The file has these Chapters:

   1. Operating Guide.
   2. Identity Registry.
   3. Knowledge Base Folder.

   The detailed Registry schema is pending design.

5. **Formatting.** Use a Google Docs file.
   Use a native table for the Identity Registry.
   Keep the directory compact.
   Add a field only when it serves a genuine directory purpose.

6. **Local QA criteria.** Check these points after each change:

   1. Each Identity has exactly one registration.
   2. Each registration has every Registry field.
   3. Each Location opens the registered identity folder.
   4. The Knowledge Base Folder Chapter opens the folder and its index.
   5. The file holds only current truth.
