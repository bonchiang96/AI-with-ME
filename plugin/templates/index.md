# 01 Index

## 1. Operating Guide

1. **Purpose.** The index lists the Identity's closed records.
   Closed records are Final Minutes and closed Job Records.
   A Meeting Agent index also lists registered Deliverables.
   Rows reference authoritative content and do not duplicate document bodies.

2. **Names.** The file name is 01 Index.
   It resides in the Identity's identity folder.

3. **Metadata.** The file needs no metadata beyond its title.

4. **Sections.** Chapter order depends on the Role:

   - A Meeting Agent index holds Deliverables first, then Meetings.
   - An Execution Agent index holds Jobs only.

   Delete the Chapters that the Role does not use.
   Each Identity may amend its columns through Minutes.

5. **Formatting.** Use a Google Docs file with native tables.
   Each key uses a letter and a number, such as M-0003:

   - D for Deliverable.
   - M for Meeting.
   - J for Job.

   Keys carry no Identity key.
   Deliverable Condition values are Draft, Stable, Frozen and Archived.

6. **Local QA criteria.** Check these points after each new row:

   1. The key is verified and follows its sequence.
   2. Each location is an exact, accessible Google Locator.
   3. A Deliverable row records a package or set, not every file.
