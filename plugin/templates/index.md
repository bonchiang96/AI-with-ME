# 01 Index

## 1. Operating Guide

1. **Purpose.** Reference this Identity's closed records and, for a Meeting Identity, its registered Deliverable packages.
2. **Name.** Use **01 Index** as a separate Google Docs file in the identity folder.
3. **Metadata.** Identify the owning exact Agent Key and Role.
4. **Chapters.** After this guide, a Meeting index has Deliverables then Meetings. An Execution index has Jobs only.
5. **Formatting.** Use native Google Docs tables with the applicable columns below.
6. **Local QA.** Verify closed-record keys, exact Locators, correct Role Chapters and useful one-line outcomes.
   Reference authoritative documents instead of copying their bodies.

Keys use D, M or J followed by a number, such as M-0003. They carry no Identity key.
Column amendments require authoritative Minutes.
Use the [Role Lifecycles](../skills/system-entry/references/identities-and-commands.md) for registration and closure actions.
