# 00 Index

## 1. Operating Guide

1. **Purpose.** The Knowledge Base folder index lists every Knowledge Base, one line per Knowledge Base.
   It tells an Agent or a person which Knowledge Bases exist and what each covers.
   It is the second Knowledge Base discovery level.

2. **Names.** The file name is 00 Index.
   It resides in the Knowledge Base folder under the System Root.

3. **Metadata.** The file needs no metadata beyond its title.

4. **Sections.** The file has these Chapters:

   1. Operating Guide.
   2. Knowledge Bases.

5. **Formatting.** Use a Google Docs file with one native table.
   Each line has three columns:

   1. Name: the Knowledge Base name.
   2. Location: the Google Locator of the Knowledge Base.
   3. Description: what the Knowledge Base covers.

   Bootstrap adds the line for the general Knowledge Base.
   Any Identity adds a line when it creates a Knowledge Base.
   Change a Description only when the Knowledge Base's Topic changes.

6. **Local QA criteria.** Check these points after each change:

   1. Every Knowledge Base in the folder has exactly one line.
   2. Each Location opens its Knowledge Base.
   3. Each Description states what its Knowledge Base covers.
