# General Knowledge Base

## 1. Operating Guide

The Knowledge Base Operating Guide is pending design.
Until it is designed, apply the rules below.

1. **Purpose.** The general Knowledge Base stores confirmed external subject knowledge and Experience that every Identity contributes.

2. **Names.** The file resides in the Knowledge Base folder under the System Root.

3. **Contents rule.** Apply the content rule in Section 4 of the [knowledge-base](../skills/knowledge-base/SKILL.md) skill.

4. **Writing.** Use Standard Mode under the Global Writing Rules.
   Consolidate every contribution into the existing content.
   Useful paragraph-level source references may be included.
