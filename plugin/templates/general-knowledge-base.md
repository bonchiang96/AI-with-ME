# General Knowledge Base

## 1. Operating Guide

1. **Purpose.** The general Knowledge Base stores confirmed external subject knowledge and Experience that every Identity contributes.

2. **Names.** The file name is General Knowledge Base.
   It resides in the Knowledge Base folder under the System Root.

3. **Metadata.** The file needs no metadata beyond its title.
   Its line in the Knowledge Base folder 00 Index holds its Name, Location and Description.

4. **Sections.** The file has a free format. Every heading is numbered.
   Chapter 1 is this Operating Guide. Chapter 2 is the contents list.
   Each further numbered Chapter holds one subject.

5. **Formatting.** Use a Google Docs file.
   Use Standard Mode under the Global Writing Rules.
   Consolidate every contribution into the existing content. Do not append.
   Useful paragraph-level source references may be included.

6. **Local QA criteria.** Check these points after each change:

   1. Every heading is numbered.
   2. The contents list names every Chapter.
   3. The file holds only currently valid content within its Scope.
   4. The 00 Index line still matches the file.
